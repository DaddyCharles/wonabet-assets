# wonabet-assets

Static assets for the WonaBet platform.

Served via [jsDelivr](https://www.jsdelivr.com/) CDN — pin to a commit SHA in consumer URLs for immutable caching.

## sportsbook_logos/

720x720 PNG logos for AU bookmakers. URL pattern:
```
https://cdn.jsdelivr.net/gh/DaddyCharles/wonabet-assets@<commit-sha>/sportsbook_logos/<slug>.png
```

Slugs: bet365 betr betright ladbrokes neds playup pointsbet sportsbet unibet
